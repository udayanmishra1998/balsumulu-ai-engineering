# CODEX.md — Instructions for OpenAI Codex

## Project Overview

This is the Balsumulu AI Engineering harness — a framework for AI agents to build real software projects through a structured ADLC (Agent Development Life Cycle).

## Conventions

- Agent definitions: `.agents/agents/`
- Skills: `.agents/skills/<skill-name>/`
- Policies: `.agents/policies/`
- Projects: `projects/<project-name>/`
- MCP server: `mcp-server/src/`
- Python 3.11+, PEP 8, type hints required
