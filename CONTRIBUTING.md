# Contributing to Balsumulu AI Engineering

Thank you for your interest in contributing!

## How to Contribute

1. **Fork** the repository
2. **Create a branch** for your feature or fix
3. **Follow conventions** outlined in `CLAUDE.md`
4. **Write tests** for new functionality
5. **Submit a PR** with a clear description

## Areas for Contribution

- **New skills** — Add skills to `.agents/skills/` and register them in `skill-registry/catalog.yaml`
- **Workflow improvements** — Enhance or add workflows in `workflows/`
- **MCP tools** — Add tools to `mcp-server/src/tools/`
- **Templates** — Add reusable templates in `templates/`
- **Integrations** — Add connectors in `integrations/`
- **Documentation** — Improve docs and examples

## Code Standards

- Python 3.11+, PEP 8, type hints
- Each skill must have its own README
- All MCP tools must have tests
- Follow the policies in `.agents/policies/`

## Reporting Issues

Open an issue with a clear description, steps to reproduce (if applicable), and expected behavior.
